Server Information

Welcome to BlossomCraft, an excellent server known for it’s amazing experiences. We are a laid-back, no grief, economy, SMP server where we value community above all else. Everyone is welcome as both Java and Bedrock players are free to join!

The server offers a variety of plugins that enhance the player experience while also staying true to Minecraft’s roots such as keep-inv, player warps, grief prevention, and more!

Show your support for the server by voting to earn free ranks which grant perks such as extra homes, cool prefixes, chest shops, and more!

Grab a seat, get comfy, and stay for a while!
